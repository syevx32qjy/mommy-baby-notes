# 要是做了这项检查，这些孩子就不会出这么大的问题！

> 更新时间：2026-09-17 (UTC+8)

提示:点击上方**东阳市人民医院 **一键关注

**本期医学指导：**
东阳市人民医院超声科 胡丽艳 副主任医师

提到心脏检查项目，大多数人第一个想到的可能会是心电图，而第一个想到心脏彩超的人很少。

如果把心脏检查比作房屋装修，查彩超是看房室有多大，墙结不结实，门是不是完好，功能是不是正常；

查心电图是看电路通不通，有没有短路漏电；

另外，还有一项心脏检查——冠脉造影，是看水管堵没堵，有没有生锈，需不需要疏通。

这三种检查用途各异，互相补充，不能替代。

结构上，心脏就像一座房屋，有两房两室，这四间房子通过四个门按照一定的顺序联通。功能上，心脏是人体的发动机，如泵一样时刻推动着血液的循环。血液通过上述这些门按照一定的方向，流向全身各处，为身体提供氧分，也从肺部汲取新鲜的氧分，周而复始的继续维持生命。

心脏彩超是对心脏的结构和功能的评估。

超声医生很多时候做的工作就是对心脏这个人体发动机进行全面检测和评估，为临床维修师们出具一份最客观的检测报告。

**七类孕妇需要做胎儿心脏检查**

- 
年龄大于35周岁的高龄孕妇；

- 
孕妇或配偶患有先天性心脏病病史，产妇曾经育有先天性心脏病患儿，有先天性心脏病家族史；

- 
孕妇既往史中有异常妊娠史，如死胎，流产，羊水过多或羊水过少等；

- 
怀孕早期服用某些药物，如氧化锂，大伦丁等；

- 
孕期接触致畸物质，如放射线等；

- 
各种类型糖尿病，结缔组织病，感染性疾病（如孕早期风疹病毒，流感病毒等感染）；

- 
抗Ro或抗La抗体阳性。 

**三类孩子，家长一定要带去医院做心脏彩超检查**

- 
吃奶困难、喂奶时常有呛咳、拒食、呼吸比较急，嘴唇发紫，这些都是心功能不全的表现；

- 
生长发育比同龄孩子明显迟缓，体重增加慢，体形消瘦、易出汗，排除营养缺乏或佝偻病后，就极有可能是先天性心脏病引起的心功能不全或和心脏供血不足；

- 
抵抗力差、上呼吸道反复感染，病情较重时可以出现喘鸣、声音嘶哑，这些绝不是一般感冒所引起的，极有可能是先天性心脏病引起。

有上述症状或体征的孩子需要及时来医院做心脏彩超检查，确诊或排除心脏疾病。

孩子哭闹会影响心超检查结果，医生建议：

- 
出生6个月以内的婴儿来检查时，家长最好带奶瓶或安抚奶嘴；

- 
6个月到1周岁的幼儿，家长可以带一些糖果或玩具；

- 
1周岁以上的幼儿可以准备一些音乐或动画片。

- 
如果孩子还是不配合，我们会根据孩子的体重用适量的镇静剂灌肠或口服，让他睡着了再做，当然这个药的副作用是非常小的。

**不管多忙，这五类成人需做心脏彩超检查**

- 
出现胸痛、胸闷气急、晕倒、发现下肢浮肿、心跳不齐等情况都需要做心脏彩超确诊或排除心血管疾病；

- 
有高血压病史、了解心脏药物的疗效需做心脏彩超评估心腔的大小及心脏功能；

- 
重大手术之前、严重外伤之后、特殊化疗药物使用前后也需要做心脏彩超评估心脏功能；

- 
已确诊患有先心病、心脏瓣膜病、心肌病、冠心病等心血管疾病患者，心梗或心脏手术后，都需要定期做心脏彩超随访。

- 
另外，40岁以上人群体检时常规做心脏彩超检查。 

**健身人群要特别引起重视**

心源性猝死是中国健身人群运动猝死的主要原因。大多数猝死者可能先天就有一些隐患没有发现，比如心脏结构有问题。

先天有缺陷的人，面对日常生活和正常锻炼时，看似健康的心脏还可以应对。但他们在进行强度过大的运动时，如进行马拉松运动时，全身耗氧量会大幅增加，同时出汗和脱水导致体内电解质浓度变化，这些共同作用于心脏，加重本身就不健康的心脏的负担，从而诱使心脏病发。

目前造成运动猝死的心源性疾病主要包括冠心病、肥厚型心肌病、瓣膜性心脏病、心脏传导系统异常、马凡综合症导致主动脉破裂等。这些疾病多数可以通过心脏彩超检查检出。
